Commissioner Training

Running NHL contests on Splash Sports

A working guide to both self-managed NHL formats — what each setting does, what the commissioner sees, and what entrants see — built from live screen recordings of real contest setups.

1. Formats overview

Splash offers two Private (Self-Managed) contest formats for NHL. Commissioners run these using Splash's tools while collecting entry fees and distributing payouts outside the platform. The format can't be changed once a contest is created, so it's worth confirming which one fits your group before you start.

NHL Pick'em

  • Participants select winners for scheduled games each week
  • Points awarded based on correct picks
  • Standard, Best Bets, or Confidence Points scoring
Best for: a weekly, ongoing contest with consistent engagement all season.

NHL Team Survivor

  • Participants pick one team to win each slate
  • A loss or missed pick eliminates the entry
  • Teams typically usable once per entry lifetime
Best for: a high-stakes elimination contest that gets harder as the season goes on.
Key differences
FeatureNHL Pick'emNHL Team Survivor
Gameplay styleWeekly picksElimination format
Number of picksMultiple per weekOne per slate
DifficultyModerateIncreases over time
Winner determinationTotal pointsLast remaining entrant

2. NHL Survivor — self-managed walkthrough

NHL Survivor works the same way as NFL Survivor, with hockey-specific differences called out below. This walks through Abbey's Test NHL Survivor Contest end to end: creating it, reviewing settings, and what entrants see.

Screen recording · Abbey's Test NHL Survivor Contest · ~3.5 min · keep this file in the same folder as this guide for playback

1Create the contest

  1. Log in to Splash Sports and select Create a Contest
  2. On the Pick a League screen, select NHL, then Continue
  3. Choose the format — Survivor or Pick'em tabs sit at the top of the format screen
  4. Name the contest (optional) and select Create contest
Note — the contest format can't be changed once created. Double-check Survivor vs. Pick'em before continuing.

2Commissioner Dashboard

After creation, you land on the Dashboard with a setup checklist: Contest Created, Set Up Entry Fee Collection (Contest Vault via LeagueSafe waives the service fee, or manage payments yourself), Review Contest Settings, and Send Invites.

Left-side menu: My Entries, Activity, Contest Details, Dashboard, Contest Settings, Entrants Manager, Invites Manager, Contest Vault, Service Fee.

3Contest settings

General

  • Contest name & description
  • Schedule: Start week defaults to Week 1 (or the nearest upcoming slate); End week defaults to Week 27
  • Entry controls: max entries per entrant, entry deadline (defaults to first game of the week), lock entries immediately
  • Hide Future Picks From Commissioner — hides picks until the deadline passes, without affecting your ability to edit them

Picksheet & Eligibility

  • Pick deadline: First game of the week (default), Last game of the week, or Custom (Saturday only, default 7:00 PM ET)
  • Team use limit — how many times an entry can pick the same team across its lifetime
  • Pick-against team limit
  • Pickset Setup: Season defaults vs. Weekly customizations
  • Eligible game days — locked to Saturday. NHL Survivor slates are Saturday-only, so there's nothing to configure here

Pick Format

  • Pick direction: Pick winner or Pick loser
  • Straight-up winners only — no Against the Spread mode (that's NFL-only)
  • Picks per slate: 1 for classic single-pick Survivor, or multi-pick with a required-picks count per week

Lives & Revivals

  • Entry lives (mulligans) — losses before elimination (1 = instant elimination)
  • Contest revivals — auto-revive the whole field if everyone's eliminated in the same slate
  • Manual revival — commissioner grants lives back individually, with a max, a cutoff window, and a last-revival-slate limit
  • No Tie Game Outcome setting — NHL games don't end in ties (OT/shootout always decides it)

Missed Picks & Auto Pick

  • Enable auto-pick to fill a missed weekly pick automatically instead of leaving it blank

Tiebreakers

  • Split (co-winners, default) or Single winner via tiebreaker stack
  • Priority list, e.g. Most Slates Survived → Strength of Victory
  • Not available for NHL: Combined Spread, Closest to Championship Total (both spread-based)

Entrant Group & Design

Same as NFL Survivor — group entrants into segments, customize the contest's banner and branding.

4Making picks (entrant view)

  1. Open the contest and go to My Entries
  2. Select + Pick on the current week's entry
  3. Make your selection before the deadline shown top-right
  4. Entry status shows a lock countdown (e.g. "Locks 11d 9h") once a deadline is set

5Contest Details

Five tabs: Overview (league, type, entrant count), Settings (actual configured values), Rules (plain-language), Schedule, Entrants.

6Entrants Manager

Commissioner-only. Filter by All / Active / Missing picks / Removed / Paused / Notes / Paid / Unpaid / Survivors. Includes CSV download, email entrants, and a pick log.

3. NHL Pick'em — self-managed walkthrough

NHL Pick'em works the same way as NFL Pick'em, straight-up only, with the hockey-specific defaults called out below. This walks through Abbey's Pick'em NHL Contest end to end.

Screen recording · Abbey's Pick'em NHL Contest · ~4 min · keep this file in the same folder as this guide for playback

1Create the contest

  1. Select NHL on the Pick a League screen, then Continue
  2. On Choose a Contest Format, select the Pick'em tab (vs. Survivor) — the NHL Pick'em card includes a "How it works" link
  3. Name the contest and select Create contest

2Contest settings

The settings sidebar for Pick'em differs from Survivor's: General, Scoring, Picksheet, Segments, Tiebreakers, Entrant Group, Design.

General

  • Contest name, description, schedule (same Week 1–27 defaults as Survivor)
  • Entry controls: max entries per entrant can be greater than 1 (set to 2 in the recording), entry deadline, lock entries immediately
  • Hide Future Picks From Commissioner — same toggle as Survivor

Scoring

  • Weighted scoring — a per-week point multiplier (1x by default) to amplify certain weeks
  • Drop Worst Week is also available

Picksheet

  • Pick deadline: First game of the week (default), Last game, or Custom
  • Picks per week: defaults to Pick All Games; can switch to a custom count (default 5, range 1–200)
  • Enable Best Picks Per Week — bonus points for designated picks
  • Autopick: on/off, plus who sets it — Commissioner sets for all or Each player chooses — with a default team pick (e.g. "All home teams") and a max auto-picks cap
  • Weekly customizations — per-game Must Pick flag and point value (defaults to 10, editable per game)
  • Eligible game days — locked to Saturday, same as Survivor
  • No Over/Under picks for NHL Pick'em (available for NFL, not NHL)

Tiebreakers

  • Weekly and Season Leaderboard Tiebreakers — ordered priority lists, editable any time, even mid-contest
  • Weekly tiebreaker — entrants predict the combined score of a designated game each week, set via Tiebreaker schedule

Segments, Entrant Group & Design

Same as NFL Pick'em — Segments split the leaderboard into sub-groups; Entrant Group and Design work identically to Survivor.

3Making picks (entrant view)

  1. Go to My Entries — shows the current week and how many picks are still missing
  2. Select + Pick to open the picksheet — each game shows both teams, win probability %, and a single-select Winner pick
  3. A running tracker shows progress (e.g. "12/13 Picks") plus a Tiebreaker entry field
  4. Once complete, the entry shows all picked teams and "All [N] required picks made"
  5. If autopick is on, entrants see a banner explaining picks will be made for them automatically

4Contest Details

Same five tabs as Survivor. The Settings tab surfaces the commissioner's actual configuration — e.g. Hide Future Picks: Enabled, Weekly Tiebreaker: Enabled, Point Spread mode: Straight up, Picks per week: Pick All. The Schedule tab lists games-per-week for the season, which varies with the actual NHL Saturday slate.
